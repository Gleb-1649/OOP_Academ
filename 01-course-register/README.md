# Учёт курсов и записей

У курса есть номер и преподаватель. Удалённый курс хранит платформу и ссылку, аудиторный — помещение и число мест. Общий класс `StudyCourse` позволяет получать расположение и лимит мест одинаковым способом.

Студенты записываются через отдельные объекты `Enrollment`. Они связывают человека с номером курса; сам курс список студентов не хранит. Каталог `CourseStore` использует словарь по номерам.

Что можно делать:

1. Добавить курс или удалить его вместе с зачислениями.
2. Назначить преподавателя и найти все его курсы.
3. Записать студента, отменить запись, получить участников курса.

Повторная запись запрещена. Для аудиторного курса проверяется вместимость. Удаление курса очищает его зачисления: если создать курс с тем же номером, старые студенты в нём не появятся.

`Teacher` и `Student` наследуют `Person`. Помимо имени у преподавателя есть кафедра, а у студента — группа. Чтение каталога выделено в `ICourseCatalog`.
