# Рюкзак персонажа

В рюкзаке есть мечи, доспехи, лечебные зелья и предметы для квестов. Все они наследуют `InventoryItem`, но действия у них разные. Описания возвращает `DescribeContents()`, надетые вещи помечаются отдельно.

Снаряжение занимает один из двух слотов: оружие или защита. При замене слота предыдущая вещь остаётся в рюкзаке. Пока вещь надета, удалить её нельзя. Один экземпляр предмета нельзя одновременно положить в две сумки.

Улучшения идут от уровня 0 до 3. Меч получает по 3 к атаке за уровень, доспех — по 2 к защите. Сервис `ItemUpgradeService` находит вещь и вызывает её улучшение; бонус надетого предмета сразу участвует в итоговых характеристиках.

Зелье нельзя выпить при полном здоровье — оно остаётся на месте. После успешного лечения оно исчезает из рюкзака и получает `IsUsed`. Это работает и при прямом `HealthPotion.Use(stats)`. Повторное применение или добавление израсходованного зелья отклоняется.

### Как разделены обязанности

**S.** `PlayerStats` хранит характеристики, `PlayerInventory` управляет содержимым и слотами, `ItemUpgradeService` выполняет улучшение.

**O.** Новый вид предмета добавляется через наследование и нужные интерфейсы. Хранение при этом не меняется. Для совершенно нового слота понадобится расширить `EquipmentSlot`.

**L.** Базовый предмет обещает только общие данные и `Describe()`. Квестовый предмет выполняет этот договор без ненужных методов экипировки или лечения.

**I.** `IEquipment`, `IConsumable`, `IUpgradeable` и `IItemLookup` решают отдельные задачи. Предмет реализует только нужные возможности.

**D.** Сервис улучшения работает через `IItemLookup` и `IUpgradeable`. В тестах поиск подменяется другой реализацией.

Вместимость и вес не учитываются. Вместо объединения предметов выбрано улучшение.
